## 📋 Descrição do Projeto
O **Conecta Campus** é uma plataforma desenvolvida para facilitar a navegação e o acesso a informações essenciais sobre os principais espaços do campus universitário.

## 📄 Páginas do Projeto
- `index.html`: Página inicial com apresentação e destaques dos locais do campus.
- `detalhes.html`: Informações detalhadas sobre a Biblioteca Central, seus serviços, horários e recursos de acessibilidade.
- `locais.html`: Lista com todos os locais catalogados.
- `integrantes.html`: Apresentação da equipe de desenvolvimento.
